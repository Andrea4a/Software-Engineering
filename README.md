# ⚙️ Rule-Based Desktop Automation System

**Software Engineering | Java | JavaFX | Agile Scrum**

A desktop application developed in **Java** to automate system operations through configurable rules based on events, time conditions and file-related triggers.

The project focuses on Object-Oriented Programming, software architecture, design patterns and collaborative development using the **Agile Scrum methodology**.

Developed as a university group project during the Master's Degree in Computer Engineering at the **University of Salerno**.

## 🚀 Key Features

- **Rule-Based Automation:** Create and manage rules that execute actions when specific conditions are met.
- **Multiple Triggers:** Support time-based scheduling, file existence, file size and external program conditions.
- **Automated Actions:** Perform file operations, launch programs, display messages and play audio.
- **Multiple Actions:** Associate multiple actions with a single rule.
- **Rule Management:** Manage rule execution through active, inactive and sleeping states.
- **Desktop Interface:** Graphical user interface developed using JavaFX.

## 🛠️ Technologies Used

- **Language:** Java

The application follows the **MVC architectural pattern** to separate business logic, user interface and application control.

Several design patterns were adopted to improve code organization, extensibility and maintainability:

- **Singleton:** Centralized management of automation rules.
- **Composite:** Execution of multiple actions through a unified interface.
- **State:** Management of different rule execution states.
- **Factory:** Creation of configurable triggers and actions.
